Now let's go deeper

How do you know if an LLM's evidence judgment matches a human's?

FreshProof decides, for each claim and source pair, whether evidence is sufficient, the source is appropriate, and the resolution is correct. That is a subjective judgment. To ship it in production, you need to be able to measure it.

This is the problem we spent weeks testing.

Methodology

A three-step evaluation framework

Borrowed from ML eval best practices and applied to a production routing system.

1

Build a human gold set

45 real claims from lower dB articles. A human reviewer makes the ground-truth decision for each. This becomes the benchmark every model must be measured against.

2

Calibrate a deterministic routing policy

Identify every failure mode and rewrite the routing rules to match all 45 human decisions. The calibrated policy encodes what correct human judgment looks like as explicit rules — giving us a precise ceiling to aim for.

3

Benchmark models against the gold set

Run each candidate model on the same 45 claims with the same prompt. Agreement rate with human gold is the single metric. Then validate on a separate held-out set to check for overfitting.

Calibration

What the calibrated policy actually means

After identifying all 17 failure cases, we rebuilt the routing rules to correctly handle each one. Policy v2 now scores 45/45 on the gold set — not because it memorized the answers, but because it correctly encodes the decision logic humans actually apply. That score is the ceiling: it defines what perfect alignment looks like. Models are then tested to see how close they can get using only prompt examples.

Interpretation

Why didn't the largest models win?

gpt-5-nano outscored gpt-5-mini. Qwen 1.7B matched Opus. These results are counterintuitive and worth interrogating.

  • Classification, not generation. This task requires choosing from a small set of routing labels. Larger generative capacity can be a liability when the correct answer is to follow explicit rules precisely.
  • Instruction adherence vs. reasoning. Smaller, constraint-trained models tend to follow routing rules more literally. Larger models may reason around them, drifting from the prompt's explicit logic into plausible-sounding alternatives.
  • GPT-5 nano is optimized differently. Nano-tier models in this family are trained for fast, precise instruction-following. The mini series trades some of that precision for broader generative range — useful for many tasks, counterproductive for strict label routing.
  • The Qwen 1.7B result needs scrutiny. Its 45/45 score is in-sample: the few-shot examples are drawn from the same 45 gold claims. This is why the held-out 20-claim validation set exists — to separate calibration from generalization.
